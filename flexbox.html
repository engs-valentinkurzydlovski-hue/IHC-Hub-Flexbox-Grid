O que é Flexbox?

O Flexbox é um recurso do CSS utilizado para organizar elementos em uma dimensão: linha ou coluna. Ele facilita o alinhamento e a distribuição dos espaços.

1. Display Flex

A propriedade display: flex; transforma o elemento pai em um contêiner flexível.

Item 2
Item 3
.container {
    display: flex;
    gap: 10px;
}

2. Flex Direction

A propriedade flex-direction define a direção dos elementos.

Row: elementos em linha

Column: elementos em coluna

.container {
    display: flex;
    flex-direction: column;
}

3. Justify Content

A propriedade justify-content controla a distribuição dos elementos no eixo principal.

1
2
3
.container {
    display: flex;
    justify-content: space-between;
}

4. Align Items

A propriedade align-items alinha os elementos no eixo transversal.

Pequeno
Alto
Pequeno
.container {
    display: flex;
    align-items: center;
}

Quando utilizar Flexbox?

  • Para alinhar itens de um menu.
  • Para centralizar elementos.
  • Para organizar botões e cartões em uma linha.
  • Para distribuir espaços entre elementos.
