O que é CSS Grid?

O CSS Grid é um recurso que permite organizar elementos em duas dimensões, trabalhando com linhas e colunas. É muito útil para criar layouts completos de páginas.

1. Display Grid

A propriedade display: grid; transforma um elemento em um contêiner de grade.

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 10px;
}

2. Grid Template Columns

A propriedade grid-template-columns define a quantidade e a largura das colunas. O valor 1fr representa uma fração do espaço disponível.

3. Grid Gap

A propriedade gap define o espaço entre as linhas e as colunas da grade.

    display: grid;
    grid-template-columns: repeat(3, 1fr);

}

4. Grid Template Areas

Com grid-template-areas, podemos nomear regiões e definir onde cada parte da página ficará.

Cabeçalho
Menu
Conteúdo principal
Rodapé
.container {
    display: grid;
    grid-template-columns: 1fr 3fr;
    grid-template-areas:
        "cabecalho cabecalho"
        "menu conteudo"
        "rodape rodape";
}

Quando utilizar Grid?

  • Para criar layouts de páginas inteiras.
  • Para organizar galerias de imagens.
  • Para montar painéis com linhas e colunas.
  • Para posicionar áreas específicas de um site.
